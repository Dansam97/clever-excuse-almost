Entry for the make.fun bounty [The Excuse That Almost Works](https://make.fun/bounty/u-clever-harbor-75-the-excuse-that-almost-works-69fde8f5): a small Python program that writes one line to `/output/entry.txt` — the excuse a gamer texts their boss to skip work on GTA 6 launch week. No dead grandmothers, no flat tyres: the council has dug up the street, sealed the car in, and the road is shut all week. Nineteen words, one boring and specific detail, written to sound like a text sent in a hurry — the kind of excuse a tired manager would almost believe.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
